Notre réflexion

L'intérêt de voir si actuellement, il y a des viandes qui n'ont jamais été vendus, c'est de voir en un premier temps les produits qui ne marchent pas et ainsi donc de voir les produits où il faudrait baisser le prix ou renégocier avec le fournisseur.

Ce qu'on a fait

La requête affiche ce nombre par rapport au nombre total de produits carnés au catalogue, pour savoir si la viande se vend. Elle liste aussi les produits concernés, avec leur fournisseur et leur prix de vente, afin de décider de baisser les prix ou d’arrêter de s’approvisionner chez eux.

SELECT
    P.NomProd,
    F.Societe,
    ROUND(P.CoutAchat * C.CoefMarge, 2) AS Prix,
    ( SELECT COUNT(*)
        FROM Produit AS P
            INNER JOIN Categorie AS C ON P.CodeCateg = C.CodeCateg
        WHERE C.NomCateg = "Viandes"
            AND P.RefProd NOT IN (
                SELECT DetailCommande.[Réf produit]
                FROM DetailCommande
            )
    ) AS Nombres_non_vendus,
    ( SELECT COUNT(*)
        FROM Produit AS P
            INNER JOIN Categorie AS C ON P.CodeCateg = C.CodeCateg
        WHERE C.NomCateg = "Viandes"
    ) AS Nombres_total
FROM (
    Categorie AS C
    INNER JOIN Produit AS P ON C.CodeCateg = P.CodeCateg
)
INNER JOIN Fournisseur AS F ON P.NoFour = F.NoFour
WHERE
    C.NomCateg = "Viandes"
    AND P.RefProd NOT IN (
        SELECT DetailCommande.[Réf produit]
        FROM DetailCommande
    )
ORDER BY
    P.NomProd;
