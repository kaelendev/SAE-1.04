Notre réflexion

L'intéret de cette requête est de voir s'il y a des partenaires client qui commande autants qui des clients pilotes est le fait de s'il faudrait insister que les clients ameners leurs partaines à commander chez Kdou.

Ce qu'on a fait

La requête compare le nombre de commandes de chaque pilote à celui de chacun de ses partenaires. Seuls les clients ayant au moins une commande sont conservés, car sans commande le partenariat ne rapporte rien. Elle sert à juger si le partenariat est bénéfique.

SELECT
    C1.Contact AS Client,
    Cclient.NB AS Client_commande,
    C2.Contact AS Partenaire,
    Cpartenaire.NB AS Partenaire_commande
FROM (
    (
        Clientele AS C1
        INNER JOIN Clientele AS C2 ON C1.CodeCli = C2.CodeCliPart
    )
    INNER JOIN (
        SELECT C.CodeCli, COUNT(C.[N° commande]) AS NB
        FROM Commande AS C
        GROUP BY C.CodeCli
    ) AS Cclient ON C1.CodeCli = Cclient.CodeCli
)
INNER JOIN (
    SELECT C.CodeCli, COUNT(C.[N° commande]) AS NB
    FROM Commande AS C
    GROUP BY C.CodeCli
) AS Cpartenaire ON C2.CodeCli = Cpartenaire.CodeCli
WHERE
    Cpartenaire.NB = Cclient.NB
ORDER BY
    C1.Contact;
