Notre réflexion

L'intéret de cette requête est de voir s'il y a des partenaires qui commande autants que les clients, afin est le fait de voir si il faudrait insister les clients à amener leurs partaines à commander chez Kdou.

Ce qu'on a fait

Pour cela, il fallait faire une jointure entre la table client et elle-même avec l’identifiant du client et celui de son partenaire puis, faire une sous-requête dans le from pour récupérer une table commande avec l’id des clients et le nombre de commandes pour les associer aux deux tables de clients puis, il a juste fallu de faire la sélection où on prend les lignes où le nombre de commandes des partenaires est égale aux nombres de commandes de clients. Et puis on a trié par nom de client et on a affiché le nom du client, son nombre de commande et la même chose pour le partenaire afin de voir si les partenaires commandes autant que les clients qui les ont invités 

SELECT
    C1.Contact AS Client,
    Cclient.NB AS Client_commande,
    C2.Contact AS Partenaire,
    Cpartenaire.NB AS Partenaire_commande
FROM (
    (
        Clientele AS C1
        INNER JOIN Clientele AS C2 ON C1.CodeCli = C2.CodeCliPart
    )
    INNER JOIN (
        SELECT C.CodeCli, COUNT(C.[N° commande]) AS NB
        FROM Commande AS C
        GROUP BY C.CodeCli
    ) AS Cclient ON C1.CodeCli = Cclient.CodeCli
)
INNER JOIN (
    SELECT C.CodeCli, COUNT(C.[N° commande]) AS NB
    FROM Commande AS C
    GROUP BY C.CodeCli
) AS Cpartenaire ON C2.CodeCli = Cpartenaire.CodeCli
WHERE
    Cpartenaire.NB = Cclient.NB
ORDER BY
    C1.Contact;
