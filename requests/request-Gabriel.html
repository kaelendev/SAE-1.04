Ma réflexion

Pour mon indicateur personnel, j’ai voulu savoir où se trouvent les principaux fournisseurs de KDou, ceux qui contribuent à son chiffre d’affaires. Cela permettrait à l’entreprise de déterminer si les fournisseurs situés hors de France sont intéressants pour établir des partenariats.

Comment cela a été réalisé

Pour cela, j’ai joint les tables Produit, DétailCommande, Catégorie, Fournisseur et Pays. J’ai ensuite regroupé les fournisseurs à l’aide de deux fonctions IIf pour regroupé les fournisseurs français si leurs pays est la France. Si cela n'est pas le cas, je les regroupe en les fournisseurs des autres pays de l’Union européenne si il vient d'un pays de UE et les autres sont regroupés en Hors UE. Enfin, j’ai calculé le chiffre d’affaires total et la quantité de produits vendus afin de comparer facilement les différents groupes et voir quel groupe est le plus intéressants à investir. 

        
           SELECT 
     IIf(
        pa.PaysFR = "France",
        "France",
          Iif(pa.UE = True, "Union européenne", "Hors UE")
    )   AS [Zobe de provenance],
     Sum(d.Quantité * p.CoutAchat * c.CoefMarge) AS [CA zone],
      Sum(d.Quantité) AS [Unités vendues]
  FROM
    (
        (
            (
                DetailCommande   AS d
                 INNER JOIN Produit AS p   ON d.[Réf produit] = p.RefProd
            )
              INNER JOIN Categorie   AS c  ON p.CodeCateg = c.CodeCateg
        )
          INNER JOIN Fournisseur   AS f ON p.NoFour = f.NoFour
    )
      INNER JOIN Pays   AS pa ON f.NoFour = pa.NoPays
  GROUP BY
     IIf(
        pa.PaysFR = "France",
        "France",
          Iif(pa.UE = True, "Union européenne", "Hors UE")
    );
