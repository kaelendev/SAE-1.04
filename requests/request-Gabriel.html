Ma réflexion

Pour mon indicateur personnel j’ai voulu savoir où se trouvais les principaux fournisseur de Kdou qui font son chiffres d'affaires cela permetteris à l'entreprise si les fournisseur hors de France sont intéressant pour faire des patenariats

Comment cela à été réalisé

Pour cela, j'ai fait une jointure entre les tables produit, détails commandes, catégories, fournisseur et pays. Et puis, j'ai regroupé grâce un double IIf. Si le pays du fournisseur est la France on regroupe entre Français, sinon si il fait partie de l'union européenne on l'associe avec les autre membres de l'union euro^é et si non encore on les regroupes dans la zone no UE. Et puis on fait la somme du chiffres d'affaires des fournisseurs et on fait la somme de la quantité de produits vendues pour pouvoir comparer les différents groupes facilement 

        
           SELECT 
     IIf(
        pa.PaysFR = "France",
        "France",
          Iif(pa.UE = True, "Union européenne", "Hors UE")
    )   AS [Zobe de provenance],
     Sum(d.Quantité * p.CoutAchat * c.CoefMarge) AS [CA zone],
      Sum(d.Quantité) AS [Unités vendues]
  FROM
    (
        (
            (
                DetailCommande   AS d
                 INNER JOIN Produit AS p   ON d.[Réf produit] = p.RefProd
            )
              INNER JOIN Categorie   AS c  ON p.CodeCateg = c.CodeCateg
        )
          INNER JOIN Fournisseur   AS f ON p.NoFour = f.NoFour
    )
      INNER JOIN Pays   AS pa ON f.NoFour = pa.NoPays
  GROUP BY
     IIf(
        pa.PaysFR = "France",
        "France",
          Iif(pa.UE = True, "Union européenne", "Hors UE")
    );
