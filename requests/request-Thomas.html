Ma réflexion

Pour mon indicateur personnel j’ai voulu lister les 3 sociétés qui délivre le plus de commande de produits étant dans la catégorie "Viandes" en 2021. Cette commande peut être adaptée pour suivre chaque catégorie sur chaque année (je n'ai pas les compétences pour le faire).

Cela permettrait de savoir vers quelle société de diriger pour s'informer sur le marché de la viandes, est-ce que ces sociétés auraient besoin d'autres fournisseurs de produits dans la catégorie "Viandes" ?

Comment cela a été réalisé

Cette requête SQL a été faite en faisant une jointure entre la table Commande et la table DetailCommande pour obtenir la référence du produit de la commande que l'on va utiliser sur une autre jointure avec la table Produit qui nous le code de la catégorie du produit. Ce code de catégorie va nous permettre d'accéder, à travers une jointure à la table Categorie, au nom de la catégorie pour laquelle nous voulons le top 3 des sociétés avec le pus de commande dans celle-ci. La dernière jointure est celle de la table Fournisseur qui nous permet d'accéder au nom de la société.

On trie pour n'avoir que les société de la catégorie "Viandes" et sur les commandes passées en 2021.
On groupe par nom de société en selectionnant le nom de la société et le nombre de commande dans la catégorie associée choisie et on peut enfin afficher le 3 premiières sociétés ayant fait le plus de commande par ordre décroissant avec leur nombres de requêtes respectives dans cette catégorie à chacune. 

SELECT TOP 3 F.Societe, COUNT(C.[N° commande]) AS NbCommandes
FROM Commande AS C
    INNER JOIN DetailCommande AS Dc ON C.[N° commande]=Dc.[N° commande]
    INNER JOIN Produit AS P ON P.RefProd=Dc.[Réf produit]
    INNER JOIN Categorie ON Categorie.CodeCateg=P.CodeCateg
    INNER JOIN Fournisseur AS F ON F.NoFour=P.NoFour

WHERE Categorie.NomCateg LIKE 'viandes'
AND YEAR(C.DateCde)=2021
GROUP BY F.Societe
ORDER BY 2 DESC;
